# V2.0 交付与上线清单

## 交付物

- `backend/`：可构建 API 源码、8 个只向前 Flyway 迁移、6 个自动化测试。
- `frontend/`：可构建 Web 源码、3 个单元测试、4 个真实浏览器端到端流程、Nginx 生产配置。
- `compose.yaml`、`.env.example`：MySQL + Redis + API + Web 验收环境。
- `deploy/`：原生主机启停、发布、Nginx、数据库备份脚本。
- `docs/`：需求完成矩阵、验收边界、运行/备份/回滚手册。

## UAT 验收用例

1. 从训练首页进入顺序、随机、专项练习；验证单选、多选、判断、场景、简答五种题型和即时解析。
2. 答错后题目自动进入错题本，答对订正后退出；收藏开关、分类/题型/集合筛选和学习统计保持一致。
3. 模拟考试答题期间不得返回正确答案与解析；完成后显示成绩，并可生成匿名、有有效期的公开分享页。
4. 上传小于 5MB 的 PDF/DOCX，确认解析文本和目标岗位；错误扩展名、伪造魔数和大文件必须被拒绝。
5. 粘贴 JD，先看到结构结果，再确认生成带题型、难度、考察点和来源的题集。
6. 开始、回答、刷新恢复、暂停恢复、跳题、主动结束；重复提交不得推进两次或重复扣费。
7. 预占后 15 分钟不开始应自动释放；没有任何有效回答而结束应退回权益。
8. 报告应包含四维评分、逐题证据、三项行动、置信度和版本；同岗位第二次练习显示分差。
9. 报告最终失败应返还权益且可重试；有用/无用反馈可重复更新。
10. 创建订单、重复支付回调和重复退款都只能记账一次；已消耗的购买权益不能自动退款。
11. 正式账号数据导出完成后可下载 JSON；注销必须再次验证密码，完成后旧 Token 失效；导出/删除还应覆盖训练、错题和收藏数据。

## 发布前必须由项目方提供并签字

- [ ] 生产域名、TLS 证书、CORS 域名、WAF/CDN 策略。
- [ ] MySQL/Redis 托管实例、备份保留周期、跨区恢复目标和告警联系人。
- [ ] 至少 32 字节随机支付回调密钥；真实商户号、证书、账单下载权限与退款规则。
- [ ] 模型网关 URL/密钥、允许的数据地域和留存设置；离线评测集通过率与人工抽检结论。
- [ ] 邮件/短信供应商、发信域名、模板审批和退订/投诉流程。
- [ ] 服务协议、隐私政策、儿童/敏感信息规则、第三方处理者清单和数据留存/备份删除周期。
- [ ] 文件病毒扫描或独立解析沙箱；恶意 PDF/DOCX 样本测试报告。
- [ ] Java 21/MySQL 8.4 环境完成容量、渗透、依赖漏洞、故障恢复和数据恢复演练。
- [ ] 客服、退款人工复核、报告质量抽检和安全事件响应值班人。

上述条目是外部凭据、基础设施或组织审批，不能由源码仓库自行生成。未全部完成时，只允许内部/UAT 或免费受控灰度，不允许对公网宣称正式收费上线。

## 发布判定

- 自动化门禁全部为绿。
- Flyway 在生产同版本 MySQL 的预演库从空库和最近备份各演练一次。
- 备份文件通过解压和实际恢复校验；只验证 `mysqldump` 结束标记不算恢复成功。
- 关键路径人工 UAT 全部通过，订单/权益/隐私删除需保存验收证据。
- 监控能看到健康、错误率、延迟、Outbox 积压、报告失败、Redis 降级、支付回调失败和隐私请求失败。
