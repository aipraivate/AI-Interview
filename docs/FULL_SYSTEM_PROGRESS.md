本机验证命令：

```bash
cd backend && ./mvnw -Djava.version=17 test
cd ../frontend && npm run build && npm run test:unit -- --run && npm run lint
```

项目生产基线仍为 Java 21；`-Djava.version=17` 只用于本机缺少 JDK 21 时的兼容验证，不改变交付基线。

## 不应被误读为“已接通”的内容

- 支付：已经具备安全回调和账务边界，但当前 Web 明示为沙箱，不发生真实扣款；真实微信/支付宝/收单渠道需要商户资料与官方 SDK。
- AI：未配置生产网关时使用确定性本地模型，便于离线验收；公网发布必须提供经评测的模型网关和密钥。
- 通知：导出/删除状态可查询和下载；短信/邮件通知需要发信域名、模板和供应商凭据。
- 文件：原文件不落库，已有大小/格式/魔数和解析库保护；独立恶意文件扫描/解析沙箱需要基础设施配合。
- 合规：代码实现了同意留痕、导出、注销和去标识化，隐私政策、服务协议、留存周期及处理者清单仍须法务确认。
